# Обратное распространение и autograd

Занятие курса «Искусственный интеллект» для 10 класса (практическая работа №1, часть 2Г). Ученики разбираются, как сеть находит вклад каждого веса в ошибку, пишут свой маленький механизм автоматического дифференцирования (класс `Value`), проверяют градиенты PyTorch численно и пишут цикл обучения, который используется во всех следующих работах.

## Теория (презентация)

1. **Граф вычислений** – формула как граф из простых операций, градиент показывает, куда двигать вес.
2. **Цепное правило** – производная цепочки, обратный проход для $L = (wx + b - y)^2$, ветвление, градиенты сети XOR, стоимость обратного прохода.
3. **Autograd** – как это работает в PyTorch, накопление градиентов, цикл обучения в пять строк, мини-пакеты.
4. **Пишем autograd на Python** – как хранить граф в коде, план практики.

## Практическая работа

Два сквозных примера: выражение $L = (wx + b - y)^2$ и сеть XOR из части 1С с «испорченным» весом.

1. Класс `Value`: сложение и умножение.
2. Активации и полный обратный проход.
3. Выражение со слайда и один шаг спуска.
4. Сеть XOR на `torch` и проверка градиентов.
5. Цикл обучения на PyTorch.
6. Обучение по мини-пакетам на данных «две луны»: `train_epoch` и `evaluate`.

Задания повышенной сложности: микро-библиотека `Neuron` / `Layer` / `MLP` в духе micrograd, обучение без `zero_grad`, мертвые нейроны, влияние размера пакета.

**Правило работы:** в заданиях Г1–Г3 – только Python и `math`, `torch` лишь в ячейках сверки. Начиная с Г4 – `torch`, autograd (`.backward()`) и `torch.optim`.

## Как работать

1. Откройте ноутбук в Jupyter или Google Colab.
2. В ячейках с заданиями замените `...` своим кодом (подсказка – в комментарии `# <--`).
3. Сверьте напечатанное значение с тем, что указано после слова «ожидается».
